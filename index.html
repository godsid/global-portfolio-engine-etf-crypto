คู่มือการคำนวณและกลยุทธ์ (Calculation Step-by-Step)

อธิบายขั้นตอนการทำงานอย่างละเอียดพร้อมสูตรคณิตศาสตร์และตัวอย่างตัวเลข

1 Liquidity Filter Calculation (การคัดกรองสภาพคล่อง)

ก่อนเริ่ม Backtest ระบบจะทำการคัดเลือก Asset ที่มีมูลค่าการซื้อขายเฉลี่ยสูงสุด $N$ อันดับแรก โดยใช้สูตร Average Daily Value (ADV)

สูตรคำนวณ (Formula):

$$ ADV_i = \frac{1}{W} \sum_{t=1}^{W} (Price_{i,t} \times Volume_{i,t}) $$
  • $ADV_i$: มูลค่าการซื้อขายเฉลี่ยต่อวันของสินทรัพย์ $i$
  • $W$: Window Period (จำนวนวันที่ใช้คำนวณย้อนหลัง เช่น 30 วัน)
  • $Price_{i,t}$: ราคาปิดของสินทรัพย์ $i$ ณ วันที่ $t$
  • $Volume_{i,t}$: ปริมาณการซื้อขายของสินทรัพย์ $i$ ณ วันที่ $t$
ตัวอย่างการคำนวณ (Numeric Example): สมมติ $W = 3$ วัน (เพื่อความง่าย) และต้องการคัด Top 1

Asset A:
Day 1: Price $100, Vol 1,000 -> Value $100,000 Day 2: Price $102, Vol 1,200 -> Value $122,400 Day 3: Price $101, Vol 800 -> Value $80,800 ADV(A) = (100,000 + 122,400 + 80,800) / 3 = $101,066.67
Asset B:
Day 1: Price $50, Vol 5,000 -> Value $250,000 Day 2: Price $52, Vol 4,000 -> Value $208,000 Day 3: Price $51, Vol 4,500 -> Value $229,500 ADV(B) = (250,000 + 208,000 + 229,500) / 3 = $229,166.67

สรุป: ระบบจะเลือก Asset B เข้าพอร์ต เพราะมี ADV สูงกว่า

2 Strategy Allocation Logic (ตรรกะการจัดพอร์ต)

1. Equal Weight (1/N)

แบ่งเงินลงทุนเท่ากันทุกตัว โดยไม่สนใจผลตอบแทนหรือความเสี่ยง

$$ w_i = \frac{1}{N} $$
Asset A, B, C, D (N=4)
Weight = 1/4 = 25% ต่อตัว

2. Rank All (Score Based)

ให้น้ำหนักตามอันดับความแรง (Momentum Score) ยิ่งอยู่อันดับสูง ยิ่งได้น้ำหนักมาก

$$ w_i = \frac{Score_i}{\sum Score} $$ โดยที่ $$ Score_i = N - Rank_i + 1 $$
มี 3 Assets (N=3) เรียงตาม Momentum:
1. Asset A (Rank 1) -> Score = 3
2. Asset B (Rank 2) -> Score = 2
3. Asset C (Rank 3) -> Score = 1
Sum Score = 3+2+1 = 6
Weight A = 3/6 (50%), Weight B = 2/6 (33.3%), Weight C = 1/6 (16.7%)

3. Top 5 Leader (Equal)

เลือกเฉพาะ 3 ตัวท็อปที่มีโมเมนตัมสูงสุด แล้วแบ่งเงินเท่ากัน (ตัดตัวที่เหลือทิ้ง)

$$ w_i = \begin{cases} 1/3 & \text{if Rank} \le 3 \\ 0 & \text{otherwise} \end{cases} $$
เรียงลำดับ: A(1), B(2), C(3), D(4), E(5)
เลือก: A, B, C
Weight A=33.3%, B=33.3%, C=33.3% (D, E = 0%)

4. Top 5 Leader (Ranked)

เลือกเฉพาะ 3 ตัวท็อป แต่ให้น้ำหนักตามลำดับคะแนน (คล้ายข้อ 2 แต่คิดแค่ 3 ตัวแรก)

$$ w_i = \frac{K - Rank_i + 1}{\sum_{j=1}^{K} j} $$ โดยที่ $K=3$, Sum=6
เรียงลำดับ: A(1), B(2), C(3), D(4)
Weight A = 3/6 (50%)
Weight B = 2/6 (33.3%)
Weight C = 1/6 (16.7%)

5. Top 50% Filtered

ตัดหางแถวทิ้งครึ่งล่าง ลงทุนเฉพาะครึ่งบนแบบ Equal Weight

$$ K = \lceil N/2 \rceil, \quad w_i = 1/K $$
มี 10 Assets (N=10) -> เลือก Top 5 (K=5)
ลงทุน 5 ตัวแรก ตัวละ 20% (1/5)

6. Absolute Momentum (Trend Filter)

ถือเฉพาะตัวที่เป็นขาขึ้น ($Return > 0$) เท่านั้น ถ้าไม่มีให้ถือเงินสด

$$ w_i = \frac{1}{\text{Count}(Return > 0)} $$
Lookback Return:
Asset A: +5% (Buy)
Asset B: -2% (Cash)
Asset C: +1% (Buy)
Portfolio: 50% Asset A, 50% Asset C (Asset B ถูกตัดออก)

7. Dual Momentum

ต้องผ่าน 2 เงื่อนไข: 1. เป็นขาขึ้น (Absolute > 0) และ 2. เก่งกว่าตัวอื่น (Relative Top 5)

Select Top 5 where $Return > 0$, then Equal Weight
Ranking:
1. A (+10%) -> Pass
2. B (+5%) -> Pass
3. C (-2%) -> Fail (Negative)
4. D (-5%) -> Fail (Negative)
Result: ซื้อเฉพาะ A และ B อย่างละ 50% (C ไม่ถูกซื้อแม้จะติด Top 5 เพราะติดลบ)

8. Inverse Volatility

ความผันผวนต่ำ ถือเยอะ / ความผันผวนสูง ถือน้อย (Risk Parity Concept)

$$ w_i = \frac{\frac{1}{\sigma_i}}{\sum \frac{1}{\sigma_j}} $$
Asset A: Volatility ($\sigma$) = 10% (0.1) -> Inv = 10
Asset B: Volatility ($\sigma$) = 20% (0.2) -> Inv = 5
Sum Inv = 15
Weight A = 10/15 (66.6%), Weight B = 5/15 (33.3%)

9. Adaptive Aggressive

ผสมผสาน: กรองตัวที่เป็นขาขึ้นก่อน (Trend) แล้วจัดพอร์ตตัวที่เหลือด้วย Inverse Volatility เพื่อลดความเสี่ยง

Filter $Return > 0$, then $w_i \propto 1/\sigma_i$
A: Ret +10%, Vol 10% (Pass)
B: Ret +5%, Vol 5% (Pass)
C: Ret -2%, Vol 20% (Fail)

คำนวณ InvVol เฉพาะ A กับ B:
Inv A = 10, Inv B = 20, Sum = 30
Weight A = 10/30 (33%), Weight B = 20/30 (66%)
*สังเกตว่า B ได้เยอะกว่าเพราะนิ่งกว่า แม้ A จะกำไรเยอะกว่า (ปลอดภัยไว้ก่อน)
